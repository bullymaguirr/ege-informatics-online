# 🎓 Подготовка к ЕГЭ по информатике — Онлайн-занятия

Репозиторий для хранения материалов, практических заданий и кода, написанного в рамках онлайн-курса по подготовке к ЕГЭ по информатике. 

## 📁 Структура репозитория

Проект организован по темам и номерам заданий, чтобы в материалах было легко ориентироваться:

* **`python_basics.py`**  — единый файл с подробным разбором основ синтаксиса Python, шпаргалками по функциям и конструкциям, которые необходимы для успешного решения экзаменационных задач.
* **`Задание_NN/`** — персональные папки для конкретных номеров из ЕГЭ (например, `Задание_19-20-21`, `Задание_14`, `Задание_15` и т.д.).
  * Внутри каждой папки находятся:
    * `.py` файлы — скрипты с кодом и программными решениями задач.
    * `.txt`  — исходные файлы данных, прикрепленные к заданиям (например, строки для перебора или текстовые файлы из банка КЕГЭ).

## 🚀 Как использовать эти материалы

1. **Для повторения теории:** Откройте файл с разбором Python для восстановления в памяти синтаксиса и ключевых фишек (условные конструкции, циклы, генераторы списков, работа со строками, модули `itertools`, `functools` и др.).
2. **Для разбора практики:** Перейдите в папку нужного задания. Вы найдете там код решения. Для запуска кода, использующего внешние файлы, убедитесь, что файлы данных лежат в той же директории (или путь к ним указан корректно).

## 🛠 Используемый стек технологий
* **Язык программирования:** У меня Python 3.14.4
* **Среда разработки (IDE):** PyCharm
